# TicTacToe × DQN — 純 Python で作る強化学習

ニューラルネットワークから DQN エージェントまでを、**NumPy・PyTorch・TensorFlow を使わず**、標準ライブラリだけで実装したプロジェクトです
(グラフ描画のみ matplotlib。無くても動きます)。盤面サイズ n (n 目並べ) は任意で、ランダムに打つ相手と対戦させながら DQN を学習させます。

## 結果 (3×3, 各ルール 5000 局学習 → 学習を止めた DQN をランダムと各 3000 局対戦)

| 対戦ルール | DQN 先手 (勝/分/負) | DQN 後手 (勝/分/負) | 平均勝率 |
|---|---|---|---|
| 1: 常に後手 | 0.979 / 0.006 / 0.014 | 0.890 / 0.041 / 0.068 | 0.935 |
| 2: 常に先手 | 0.964 / 0.011 / 0.025 | 0.781 / 0.029 / 0.191 | 0.872 |
| 3: 勝者が後手 | 0.976 / 0.010 / 0.014 | 0.890 / 0.036 / 0.073 | 0.933 |
| 参考: 理論上の最適 (対ランダム) | 0.995 / 0.005 / 0.000 | 0.934 / 0.056 / 0.010 | |

約 1000〜2000 局で頭打ちになります。ハイパーパラメーターの調整経緯・考察は `match_rnd_vs_dqn.py` の冒頭に書いてあります。
(Python 3.12.3 での 1 回の実行。シードを固定すれば同じ結果が再現します)

## ファイル構成 (下から上へ積み上がっています)

| 層 | ファイル | 役割 |
|---|---|---|
| 実験 | `match_rnd_vs_dqn.py` | ランダム vs DQN の対戦実験。勝ち/引分/負けの推移を CSV・グラフに出力 |
| | `tune_dqn.py` | ハイパーパラメーターを 1 つずつ変え、複数シードで比較 |
| | `experiment_util.py` | 乱数シードの管理、端末からの入力 |
| エージェント | `ttt_agent_DQN.py` | **DQN** (経験再生・ターゲットネットワーク・ε-greedy・合法手マスク、保存/復元) |
| | `ttt_agent_QL.py` / `match_rnd_vs_ql.py` | 表形式 Q 学習とその対戦 (比較用ベースライン) |
| | `ttt_agent_random.py` / `ttt_agent.py` | ランダムエージェント / エージェントの共通インターフェース |
| 環境 | `tictactoe.py` | n×n の TicTacToe (勝敗判定つき) |
| 自作 NN | `nn_layers.py` | 全結合層と多層ネットワーク (ミニバッチ対応の順伝播・逆伝播、**数値微分による勾配チェック**) |
| | `nn_loss.py` / `nn_optimizer.py` / `nn_activator.py` | 損失 (MSE, Huber) / 最適化 (GD, Momentum, RMSprop, Adam) / 活性化 (linear, ReLU, sigmoid) |
| | `matrix_util.py` | 行列演算 (リストのリスト) |

## 使い方

```
python3 match_rnd_vs_dqn.py        # 何目並べか・試行回数・ルールを端末で入力 (Enter で既定値)
python3 match_rnd_vs_dqn.py 3 5000 # 引数で指定 (質問は省略)
python3 nn_layers.py               # 自作 NN の動作確認 + 勾配チェック
python3 tune_dqn.py                # ハイパーパラメーター調整 (約 20 分)
```

結果は `dqn_results/` に保存されます。

## 実装で工夫した点

- **ミニバッチ対応**: バイアスのブロードキャストと勾配のバッチ方向の合計を実装し、行列積を `sum(map())` で高速化。
- **逆伝播の検証**: 全てのウェイト・バイアス・入力を数値微分と比べる `Layers.gradient_check()`。MSE・Huber・ReLU・sigmoid の各構成で一致。
- **再現性**: 乱数シードを `experiment_util.py` に集約。条件を比較するときは同じシードを使う。学習済みモデルはハイパーパラメーターと学習回数ごと保存・復元できる。
- **評価の分離**: 学習中の成績 (ε-greedy) と、学習を止めた貪欲な DQN の成績 (先手・後手別) を別々に記録。
